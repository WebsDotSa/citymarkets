  QUICK DEPLOYMENT (3 STEPS)

STEP 1: Open Terminal and Run
────────────────────────────────────────────────────────────────────────────────
cd /var/www/citymarkets.sa/city-market-app
./deploy-storybook.sh

STEP 2: Follow Prompts
────────────────────────────────────────────────────────────────────────────────
When prompted:

  "Set up and deploy ~\city-market-app?"
  → Answer: y (yes)

  "Which scope should we deploy to?"
  → Select your Vercel account (or sign up if needed)

  "Link to existing project?"
  → Answer: n (no) — creates new project

  "What is the directory to output?"
  → Press Enter (default: .)

  "Want to override the settings?"
  → Answer: n (no)

STEP 3: Wait for Deployment
────────────────────────────────────────────────────────────────────────────────
The script will:
  ✓ Build Storybook
  ✓ Create a Vercel project
  ✓ Deploy the built site
  ✓ Print the live URL

════════════════════════════════════════════════════════════════════════════════
  TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Q: "vercel command not found"
A: npm install -g vercel
   (Then try again)

Q: "Deploy fails with build error"
A: npm install
   npm run build-storybook
   (Verify it builds locally first)

Q: "Need to deploy again after changes"
A: ./deploy-storybook.sh
   (Repeatable - connects to existing Vercel project)

Q: "Don't have Vercel account"
A: Sign up free at https://vercel.com (takes 1 minute)
   Then run ./deploy-storybook.sh

════════════════════════════════════════════════════════════════════════════════
  MANUAL DEPLOYMENT (If Script Doesn't Work)
════════════════════════════════════════════════════════════════════════════════

1. Build Storybook:
   npm run build-storybook

2. Install Vercel CLI:
   npm install -g vercel

3. Deploy:
   vercel --prod --name citymarkets-storybook

4. Follow the prompts (see Step 2 above)

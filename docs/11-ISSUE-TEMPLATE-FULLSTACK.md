# Full-Stack Work Item Template

## Problem
Observable defect.

## Scope
Domain, routes, consumers, DB objects, providers.

## Root cause
Technical cause.

## Canonical implementation
Target service/module.

## Migration
Code/data/config steps.

## Tests
Unit, integration, contract, E2E.

## Acceptance
Explicit pass/fail checks.

## Rollback
Safe rollback/restore path.

## Sunset
Retirement condition for legacy code.

## Verification
Exact commands and expected results.

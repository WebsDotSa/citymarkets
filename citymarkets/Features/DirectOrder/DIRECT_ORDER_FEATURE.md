# ميزة الطلب المباشر (Direct Order)

## نظرة عامة

ميزة الطلب المباشر تتيح للعملاء:
- إنشاء طلب بدون اختيار من كاتالوج محدد
- تسجيل ملاحظة صوتية (اختياري)
- إضافة منتجات نصية حرة (مثل "دجاج مشوي بالعسل")
- اختيار عنوان التوصيل من العناوين المحفوظة
- اختيار طريقة الدفع
- تأكيد رسوم الخدمة (4 ر.س)

## الملفات

### `DirectOrderView.swift`
الواجهة الرئيسية لإنشاء الطلب المباشر مع الأقسام:

1. **عنوان التوصيل** — اختيار من قائمة العناوين المحفوظة
2. **طريقة الدفع** — مدى، فيزا، ماستركارد، أمريكان إكسبريس، Apple Pay، محفظة رقمية، تحويل بنكي
3. **ملاحظة صوتية** — تسجيل صوتي اختياري (حتى 10 دقائق)
4. **ملاحظات إضافية** — نص حر
5. **المنتجات** — إضافة منتجات نصية مع الكمية
6. **تأكيد الرسوم** — موافقة على 4 ر.س

### شاشات فرعية:
- **AddressPickerSheet** — اختيار عنوان التوصيل
- **AddDirectOrderItemSheet** — إضافة منتج نصي

## التكامل مع الـ API

### الطلب (POST /api/v1/orders/direct)

```swift
DirectOrderRequest(
    payment_method: String,        // mada, visa, etc.
    notes: String?,               // ملاحظات نصية
    voice_note_url: String?,      // رابط الملف الصوتي
    voice_note_duration: Int?,    // مدة الملف بالثواني
    customer_phone: String?,      // رقم الهاتف (للضيوف)
    fee_acknowledged: true,       // يجب أن يكون true
    delivery_address: DirectOrderAddress,
    items: [DirectOrderItem]?,
    idempotency_key: String?      // منع الطلبات المكررة
)
```

### الرد (DirectOrderResponse)

```swift
{
    "success": true,
    "orderId": "uuid",
    "orderNumber": "ORD-12345"
}
```

## التدفق

1. **زر الإضافة** — في OrdersView (أيقونة + في الأعلى)
2. **فتح DirectOrderView** — عرض النموذج كـ sheet
3. **ملء البيانات** — المستخدم يملأ جميع الحقول المطلوبة
4. **التوثيق** — المستخدم يوافق على رسوم الخدمة
5. **الإرسال** — تم الضغط على "تأكيد الطلب المباشر"
6. **الإنشاء** — يتم إرسال POST request إلى `/api/v1/orders/direct`
7. **النجاح** — إعادة تحميل قائمة الطلبات والإغلاق

## الميزات

✅ تسجيل صوتي مع عداد وقت حقيقي
✅ إدارة المنتجات النصية (إضافة/حذف)
✅ اختيار العناوين المحفوظة
✅ اختيار طرق الدفع المتعددة
✅ تأكيد رسوم الخدمة
✅ معالجة الأخطاء والرسائل
✅ حالات التحميل والانتظار
✅ منع الطلبات المكررة (idempotency key)

## حالات الاستخدام

- **الطلب الطارئ** — العميل يريد شيئاً لا يوجد في الكاتالوج
- **الطلب المخصص** — عميل يريد إضافات أو تعديلات خاصة
- **الطلب الصوتي** — العميل يفضل إملاء الطلب بدلاً من الكتابة
- **الطلب السريع** — تجاوز قائمة الاختيار المعقدة

## الأمان

- تتطلب تسجيل دخول (401 إذا لم يكن مسجلاً)
- التحقق من جانب الخادم من رسوم الخدمة
- منع الطلبات المكررة باستخدام idempotency key
- تشفير الملفات الصوتية أثناء النقل

## الأداء

- تحميل العناوين بشكل كسول
- استخدام async/await للعمليات
- حالات الخطأ واضحة
- انتظار 4 ر.س كحد أدنى للخدمة
